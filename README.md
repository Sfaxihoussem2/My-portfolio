## Overview

This repository contains the source code of my personal portfolio website. It presents my background as an Embedded Systems and IoT Engineer, showcases selected projects, skills, experience, and provides a clear way for recruiters and collaborators to contact me.

The site is designed to be clean, fast, and focused on technical content relevant to embedded systems, IoT, firmware, and full-stack connected solutions.

---

## Sections

- **About** — Professional summary and background
- **Projects** — Selected engineering work (firmware, IoT, Edge AI, robotics, full-stack)
- **Skills** — Technical stack (embedded, IoT, languages, tools)
- **Experience** — Internships, freelance work, and leadership roles
- **Contact** — Links to LinkedIn, GitHub, and other channels

---

## Technologies

- HTML5

- GitHub Pages for hosting
